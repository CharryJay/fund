# 股票组合收益对比分析工具

一个基于 Web 的股票组合收益对比分析工具，支持自定义股票组合，对比不同持仓策略的收益表现。

## 功能特点

- 📊 **多组合对比**：同时创建和对比多个股票组合的收益表现
- 📈 **收益曲线可视化**：使用 Chart.js 展示直观的收益曲线图
- 🎯 **灵活配置**：自定义股票代码和权重比例
- 📅 **时间范围选择**：支持 1 个月、3 个月、6 个月、1 年等时间范围
- 🌏 **数据来源**：Yahoo Finance 实时数据（获取失败时自动降级为模拟数据）
- 💼 **港股支持**：支持港股市场（代码格式：HK + 数字，如 HK3033、HK0700）

## 快速启动

### 方法一：使用 Python 内置服务器（推荐）

```bash
# 进入项目目录
cd /workspace

# 启动 HTTP 服务器
python3 -m http.server 8080
```

然后在浏览器中访问：http://localhost:8080

### 方法二：使用 Node.js 的 http-server

```bash
# 安装 http-server（如果未安装）
npm install -g http-server

# 启动服务器
http-server -p 8080
```

然后在浏览器中访问：http://localhost:8080

### 方法三：直接在浏览器中打开

直接双击 `index.html` 文件在浏览器中打开（某些功能可能受浏览器安全策略限制）

## 使用说明

1. **输入股票代码**：在组合 A 或组合 B 中输入股票代码（如：HK3033、HK0700、HK9988 等）
2. **设置权重**：为每只股票设置权重百分比（总和建议为 100%）
3. **选择时间范围**：点击快捷按钮选择 1 个月、3 个月、6 个月或 1 年
4. **开始对比**：点击"🚀 开始对比"按钮查看收益曲线
5. **添加/删除股票**：可以点击"+ 添加股票"增加持仓，或删除已有股票

## 数据接口说明

本工具通过以下方式获取股票数据：

1. **主要数据源**：Yahoo Finance API
   - 通过 CORS 代理（api.allorigins.win）绕过浏览器跨域限制
   - 获取真实的股票历史价格数据

2. **备用方案**：模拟数据
   - 当真实数据获取失败时（网络问题、API 限制等）
   - 自动生成确定性的模拟价格数据

### 测试数据接口

可以使用提供的测试脚本验证数据接口是否可用：

```bash
python3 test_api.py
```

测试将尝试获取几个港股的实时数据，并显示成功率。

## 技术栈

- **前端**：HTML5, CSS3, JavaScript (ES6+)
- **图表库**：Chart.js
- **数据源**：Yahoo Finance API
- **CORS 代理**：api.allorigins.win

## 注意事项

1. 港股交易时间为工作日，周末和节假日无数据
2. 实时数据依赖于 Yahoo Finance 和 CORS 代理的可用性
3. 权重总和应为 100%，系统会提示警告如果不是 100%
4. 股票代码格式：HK + 数字（如 HK3033），系统会自动转换为 Yahoo Finance 格式

## 示例组合

- **组合 A**：单一股票 HK3033（100% 权重）
- **组合 B**：多股票组合
  - HK07552（10% 权重）
  - HK9988（90% 权重）
